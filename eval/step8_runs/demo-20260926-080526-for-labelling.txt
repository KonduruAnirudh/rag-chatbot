Q16 [on-topic] How does AWS Global Accelerator help protect a Network Load Balancer's TCP listeners from SYN floods?
  gold chunks: ['AWS:50']
  answer facts: ['global accelerator has an inbuilt syn proxy']

  VECTOR (answered): AWS Global Accelerator protects an NLB’s TCP listeners by providing an inbuilt, stateless SYN proxy. It challenges new connection attempts with SYN cookies, tracks connections through the NLB, and drops spoofed traffic that cannot complete the TCP handshake, helping mitigate SYN floods [1][2].

- **Proactive SRT engagement:** When Shield Advanced detects signs of DDoS and configured health checks show application degradation, the AWS Shield Response Team contacts you directly. This requires configured health checks and always-available operations contact information. [4]
- **Customer-initiated escalation:** If a DDoS event affects application availability, subscribers with Business Support+, Enterprise Support, or Unified Operations can create an AWS Shield Support case or use the support API to escalate to the SRT. [1]
- **Detection and mitigation metrics:** Shield Advanced provides event metrics and traffic details, including anomalies and known DDoS signatures, to support investigation and response. [3]
